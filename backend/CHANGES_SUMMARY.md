## 🔒 Безопасность и контроль

### Система проверки прав:
```python
def get_current_admin(user_id: int, db: Session) -> User:
    """Проверить, что текущий пользователь - администратор"""
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(status_code=404, detail="Пользователь не найден")
    if user.role != "admin":
        raise HTTPException(status_code=403, detail="Недостаточно прав")
    return user
```

### Требования к API:
- Все admin endpoints требуют параметра `admin_id`
- Система проверяет роль администратора для каждого запроса
- Возвращается HTTP 403 при попытке неавторизованного доступа

## 📊 Примеры использования

### Создать администратора:
```bash
python scripts/create_admin.py
```

### Получить все заказы:
```bash
curl -X GET "http://localhost:8000/api/admin/reservations?admin_id=1"
```

### Обновить заказ:
```bash
curl -X PUT "http://localhost:8000/api/admin/reservations/1?admin_id=1" \
  -H "Content-Type: application/json" \
  -d '{"guests": 5, "is_confirmed": true}'
```

### Удалить пользователя:
```bash
curl -X DELETE "http://localhost:8000/api/admin/users/2?admin_id=1"
```

### Назначить администратора:
```bash
curl -X POST "http://localhost:8000/api/admin/users/3/role/admin?admin_id=1"
```
